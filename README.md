SkyBound 探索者计划 - 第二周大作业 
  
这是一个基于 HTML5、CSS3 动态流体背景、高级发光艺术字，以及纯 JavaScript Canvas 粒子击碎交互特效打造的个人主页。项目通过 Trae AI 协作开发，并已成功实现 Git 版本控制与 Vercel 自动化线上部署。 
  
**项目访问链接** 
- GitHub 代码仓库: `https://github.com/Alina-LM/My-website`  
- Vercel 线上预览: `https://my-website-xi-one-43.vercel.app/`  
  
**项目核心亮点与视觉特效** 
1. 全屏梦幻动态背景：采用现代莫兰迪流体渐变技术（Animated Gradient Background），背景在粉、紫、蓝之间丝滑自循环流动。 
2. 发光呼吸感艺术字：主标题文字采用字体渐变色（Background-clip: text），并配有霓虹发光阴影与轻微的上下悬浮呼吸动效。 
3. Canvas 粒子击碎特效：纯 JavaScript 编写的粒子物理引擎。鼠标划过大标题“SkyBound”时，文字粒子会被灵敏地“击碎并四散弹开”；鼠标移走后，粒子会自动平滑聚拢、磁吸复原。 
  
**本周学习收获与技术栈：** 
核心开发（初步）：HTML5 / CSS3 Animation / Canvas API / Vanilla JavaScript 
开发工具：腾讯 Trae IDE (结合Agent ) 
版本控制：熟练掌握 Git 本地存盘（add/commit）、代理配置（解決 443 端口连接失败）、多分支（master/main）概念以及版本回滚读档（git checkout .）。 
持续集成：打通 GitHub 远端网盘同步与 Vercel 的自动化部署流水线（实现 push 代码后线上网站自动更新）。
